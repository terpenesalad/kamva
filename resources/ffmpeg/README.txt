FFmpeg
======

Kamva uses FFmpeg (https://ffmpeg.org) as a separate program to encode MP4,
WebM and MP3 files and to convert video/audio formats on import.

This is an unmodified static FFmpeg 6.1.1 build for Windows x64, as published
by the ffmpeg-static project (https://github.com/eugeneware/ffmpeg-static,
release b6.1.1). It is licensed under the GNU General Public License version 3;
see LICENSE.txt in this folder. The corresponding source code is available from
https://ffmpeg.org/releases/ffmpeg-6.1.1.tar.xz and the build configuration from
the ffmpeg-static project.
